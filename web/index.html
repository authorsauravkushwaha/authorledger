        How your work is saved

        Everything you write is saved privately inside this browser using IndexedDB (with a synchronous localStorage mirror). Nothing is uploaded to any external server. Use "Download full backup" on the shelf anytime to keep an offline copy.

        AuthorLedger works 100% without an API key (including the Writing Pattern Report, Offline Craft Check, Compliance Report, and Manuscript Export).
